# 📖 ကုမ္ပဏီ ဗဟုသုတ လက်ထောက် (Smart Internal Knowledge Assistant) — အသုံးပြုနည်း လမ်းညွှန်

ကုမ္ပဏီတွင်း **စမတ်ဗဟုသုတ လက်ထောက်** မှ ကြိုဆိုပါသည်! ဤလမ်းညွှန်ချက်သည် ကုမ္ပဏီရှိ ဝန်ထမ်းအားလုံး အလွယ်တကူ ဖတ်ရှုအသုံးပြုနိုင်ရန် ရေးသားထားပြီး၊ ကွန်ပျူတာ သို့မဟုတ် နည်းပညာ အထူးကျွမ်းကျင်စရာ မလိုဘဲ မည်သူမဆို ချက်ချင်း အသုံးပြုနိုင်ပါသည်။

## 🌟 ဤစနစ်သည် အဘယ်နည်း? အဘယ်ကြောင့် အသုံးပြုသင့်သလဲ?

ကုမ္ပဏီ၏ နှစ်စဉ်ခွင့်မူဝါဒ၊ ဆေးခွင့်ရက်များ၊ အိမ်မှအလုပ်လုပ်ချိန် လိုက်နာရမည့် စည်းကမ်းများ သို့မဟုတ် ရုံးသုံးကွန်ရက် ချိတ်ဆက်ပုံများကို သိရှိရန် Google Drive ထဲတွင် ဖိုင်တွေ လိုက်ရှာရခြင်း၊ Slack ထဲတွင် မေးမြန်းစောင့်ဆိုင်းရခြင်းတို့ကြောင့် အချိန်ကုန်ဖူးပါသလား?

**စမတ်ဗဟုသုတ လက်ထောက်** သည် ကုမ္ပဏီရှိ စာရွက်စာတမ်းများ၊ ဝန်ထမ်းလက်စွဲများနှင့် ရုံးတွင်း စည်းမျဉ်းများကို အကုန်လုံး ဖတ်ရှုမှတ်သားထားသော သင်၏ ရုံးတွင်း ဒစ်ဂျစ်တယ် လုပ်ဖော်ကိုင်ဖက်ကောင်း ဖြစ်ပါသည်။ မည်သည့်မေးခွန်းမဆို မေးမြန်းလိုက်ပါက တိကျမှန်ကန်သော အချက်အလက်ကို စက္ကန့်ပိုင်းအတွင်း ရှာဖွေဖြေကြားပေးမည် ဖြစ်ပါသည်။

## 🚀 အဓိက အကျိုးကျေးဇူးများ — သင့်လုပ်ငန်းခွင်ကို မည်သို့ လွယ်ကူစေသလဲ?

* ⚡ **စောင့်ဆိုင်းစရာမလိုဘဲ ချက်ချင်းအဖြေရခြင်း:** HR သို့မဟုတ် IT ဌာနထံ အီးမေးလ်ပို့ပြီး ရက်ပေါင်းများစွာ စောင့်စရာမလိုတော့ဘဲ နေ့ရောညပါ အချိန်မရွေး ချက်ချင်း အဖြေရရှိနိုင်ပါသည်။
* 🛡️ **၁၀၀% တိကျခိုင်မာခြင်း:** လက်ထောက်သည် ထင်ကြေးဖြင့် ဖြေကြားခြင်း လုံးဝမပြုလုပ်ပါ။ အဖြေတိုင်းတွင် တရားဝင် ကိုးကားချက်နံပါတ်များ (ဥပမာ `[1]`, `[2]`) ပါဝင်ပြီး၊ နှိပ်ကြည့်ရုံဖြင့် သက်ဆိုင်ရာ ကုမ္ပဏီ စာရွက်စာတမ်း မူရင်းစာပိုဒ်ကို ချက်ချင်း ပြသပေးပါသည်။
* 🌐 **မြန်မာစာနှင့် အင်္ဂလိပ်စာ ၂ မျိုးလုံး အသုံးပြုနိုင်ခြင်း:** အင်္ဂလိပ်လိုဖြစ်စေ၊ မြန်မာလိုဖြစ်စေ လွတ်လပ်စွာ မေးမြန်းနိုင်ပြီး သင်မေးသည့် ဘာသာစကားအတိုင်း သဘာဝကျကျ ပြန်လည်ဖြေကြားပေးပါသည်။
* 🎫 **ကလစ်တစ်ချက်ဖြင့် အကူအညီတောင်းခံလွှာ ဖွင့်နိုင်ခြင်း:** စာရွက်စာတမ်းများထဲတွင် မပါရှိသော မေးခွန်းများအတွက် သက်ဆိုင်ရာဌာနများ (HR သို့မဟုတ် IT) သို့ အကူအညီတောင်းခံလွှာ (Support Ticket) ကို စကားပြောခန်းထဲမှပင် တိုက်ရိုက် ပေးပို့နိုင်ပါသည်။

## 📝 လွယ်ကူသော အသုံးပြုနည်း အဆင့် (၅) ဆင့်

လက်ထောက်ကို စတင်အသုံးပြုရန် စက္ကန့် ၃၀ ပင် မကြာပါ:

```
အဆင့် ၁: စကားပြောခန်းဖွင့် ➡️ အဆင့် ၂: ဘာသာစကားရွေး ➡️ အဆင့် ၃: မေးခွန်းမေး ➡️ အဆင့် ၄: အထောက်အထားစစ် ➡️ အဆင့် ၅: တုံ့ပြန်ချက်ပေး
```

1. **အဆင့် (၁) - စကားပြောခန်း (Chat) ကို ဖွင့်ပါ**  
   ဘယ်ဘက် မီနူးရှိ **AI လက်ထောက် (AI Assistant)** ကို နှိပ်ပါ။ သန့်ရှင်းသပ်ရပ်သော စကားပြောမျက်နှာပြင် ပေါ်လာပါမည်။

2. **အဆင့် (၂) - မိမိနှစ်သက်ရာ ဘာသာစကားကို ရွေးပါ**  
   စခရင်၏ အပေါ်ညာဘက်ထောင့်တွင် **EN** (အင်္ဂလိပ်) နှင့် **မြန်မာ** ဟူ၍ အချိန်မရွေး လွတ်လပ်စွာ ပြောင်းလဲနိုင်ပါသည်။

3. **အဆင့် (၃) - သိလိုသည်ကို မေးမြန်းပါ**  
   စခရင်အောက်ခြေရှိ စာရိုက်သည့်နေရာတွင် မိမိသိလိုသည်ကို ရိုက်ထည့်ပြီး ပေးပို့ရန် အပြာရောင် မြှားခလုတ်ကို နှိပ်ပါ။ သို့မဟုတ် အပေါ်ရှိ အကြံပြုထားသော ခလုတ်လေးများ (ဥပမာ *"နှစ်စဉ်ခွင့် ခံစားခွင့် မူဝါဒက ဘာလဲ?"* သို့မဟုတ် *"ကုမ္ပဏီ VPN ဘယ်လိုချိတ်ဆက်ရမလဲ?"*) ကို ကလစ်နှိပ် မေးမြန်းနိုင်ပါသည်။

4. **အဆင့် (၄) - အဖြေကိုဖတ်ရှုပြီး ကိုးကားချက်များကို စစ်ဆေးပါ**  
   အဖြေထွက်လာသောအခါ အပြာရောင် ကိုးကားချက်နံပါတ်လေးများ `[1]` ပေါ်လာပါမည်။ ၎င်းကို ကလစ်နှိပ်လိုက်ပါက ကုမ္ပဏီလက်စွဲစာအုပ်မှ မူရင်းစာပိုဒ်နှင့် စာမျက်နှာကို ညာဘက်တွင် တိုက်ရိုက် ကြည့်ရှုနိုင်ပါသည်။

5. **အဆင့် (၅) - အဆင်ပြေပါက အမှတ်ပေးပြီး လိုအပ်ပါက လက်မှတ်ဖွင့်ပါ**  
   - အဖြေကို သဘောကျပါက 👍 ကို နှိပ်ပြီး၊ မပြည့်စုံပါက 👎 ကို နှိပ်၍ အကြံပြုနိုင်ပါသည်။
   - လူကိုယ်တိုင် ထပ်မံကူညီပေးရန် လိုအပ်ပါက **လက်မှတ်ဖွင့်မည် (Open Ticket)** ကို နှိပ်၍ သက်ဆိုင်ရာဌာနထံ အကူအညီတောင်းခံလွှာ တိုက်ရိုက် ပေးပို့နိုင်ပါသည်။

## ❓ မကြာခဏ မေးလေ့ရှိသော မေးခွန်းများ (FAQ)

### ကျွန်ုပ် မေးမြန်းထားသော စကားများကို အခြားဝန်ထမ်းများ မြင်နိုင်ပါသလား?
**မမြင်နိုင်ပါ။** သင်၏ စကားပြောမှတ်တမ်းများသည် သင်၏ ကိုယ်ပိုင် အကောင့်ထဲတွင်သာ လုံခြုံစွာ သိမ်းဆည်းထားပါသည်။

### လက်ထောက်က အချက်အလက် မတွေ့ရှိပါဟု ဖြေကြားပါက မည်သို့လုပ်ရမည်နည်း?
လက်ထောက်သည် မှန်းဆဖြေကြားခြင်း မပြုဘဲ ရိုးသားစွာ အသိပေးပြီး မည်သည့်ဌာနထံ ဆက်သွယ်ရမည်ကို အီးမေးလ်၊ Slack အကောင့်များနှင့်တကွ ဖော်ပြပေးမည်ဖြစ်ပြီး Support Ticket ချက်ချင်း ဖွင့်ပေးနိုင်ပါသည်။

### မေးခွန်းမေးရာတွင် ရုံးသုံးစကားလုံး အခေါ်အဝေါ် အခက်အခဲများ သုံးရန် လိုပါသလား?
**မလိုပါ။** လုပ်ဖော်ကိုင်ဖက် အချင်းချင်း နေ့စဉ် စကားပြောသကဲ့သို့ သဘာဝကျကျသာ ရိုက်ထည့် မေးမြန်းနိုင်ပါသည်။
